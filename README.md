# Brazilian E-Commerce SQL Analysis Project
## Overview

This project explores the Brazilian E-Commerce Public Dataset by Olist using SQL. The goal is to practice practical data analysis skills by solving business style problems that commonly appear in analytics and data engineering roles.

The dataset contains information about customers, orders, sellers, products, payments, reviews, and delivery information from a large Brazilian marketplace. By working with these tables we can investigate customer behaviour, seller performance, payment patterns, and delivery operations.

The exercises in this repository focus on writing clear SQL queries that combine multiple tables, perform aggregations, and answer real business questions.

## Dataset

Source: Brazilian E-Commerce Public Dataset by Olist
Available on Kaggle.

## Main tables used in this project include:

orders
customers
order_items
order_payments
order_reviews
products
product_category_name_translation

These tables together allow us to track the lifecycle of an order from purchase to payment, shipment, delivery, and review.

## Project Goals

The main purpose of this project is to strengthen SQL skills through realistic analytical questions. The queries practice several important concepts such as:

Joining multiple tables
Aggregating data with SUM, COUNT, and AVG
Grouping results with GROUP BY
Filtering with WHERE and HAVING
Working with dates and timestamps
Using Common Table Expressions (CTEs)
Writing clean analytical queries that answer business questions

The problems were designed to move from intermediate complexity to slightly more advanced analytical tasks.

## Skills Practiced

This project helped reinforce several core SQL skills:

Data exploration using SELECT queries
Understanding table relationships and joins
Writing aggregation queries for business metrics
Handling missing values with functions such as COALESCE
Using adbanced Windows functions
Building step by step queries using CTEs
Analyzing time based trends using timestamps

These are essential skills for roles such as data analyst, analytics engineer, or data scientist.

Why This Dataset Is Useful for Learning SQL

The Olist dataset is particularly good for SQL practice because it resembles a real production database. It includes several interconnected tables and requires joining them correctly to answer meaningful questions.

Working with this dataset helps develop an understanding of how real business data is structured and how analysts extract insights from it.
